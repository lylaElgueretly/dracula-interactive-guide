# Dracula Interactive Guide

An interactive Year 7 English study guide based on Bram Stoker's *Dracula*.

## Publish with GitHub Pages

1. Create a new GitHub repository named `dracula-interactive-guide`.
2. Extract the downloaded ZIP file.
3. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
4. Open **Settings**, then **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.

The published address will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/dracula-interactive-guide/`

`index.html` must remain in the repository root because GitHub Pages uses it as the website's opening page.
